Q: What technologies are you using to build ERPify?

A: We are using a modern stack: TypeScript, Next.js for the full-stack framework, Supabase (PostgreSQL) for the database and authentication, and the Claude API via Vercel AI SDK for the AI features.

Q: How does the AI work in your ERP system?

A: We have an AI-Assisted Extension Layer. Instead of writing complex prompts, the business owner answers a guided questionnaire, and the Claude API generates custom modules (like Delivery Tracking) in the background. It is first tested in an isolated sandbox for security.

Q: How do you secure data in ERPify?

A: We use Tenant-Level Encryption (a Zero-Knowledge Architecture) so even admins can't read a tenant's financial data. We also use Row-Level Security (RLS) in Supabase for strict data isolation.
