# Core BSCS Coursework & Study Notes (UMT Sialkot)

As a 7th-semester BSCS student at the University of Management and Technology (UMT) Sialkot Campus maintaining a 3.18 CGPA, my academic curriculum has covered both theoretical computer science and applied software engineering.

My core coursework includes:
- Artificial Intelligence & Agentic Systems: Search algorithms (Hill Climbing, A* heuristics), Retrieval-Augmented Generation (RAG), lexical retrieval with BM25, dense vector embeddings using Sentence Transformers, Reciprocal Rank Fusion (RRF), and grounded LLM prompting.
- Advanced Database Management Systems (ADBMS): Relational database design, normalization, DDL/DML/DCL SQL query optimization, Object-Oriented Databases (OODB), Object-Relational Databases (ORDB), file organization techniques (Heap, Sorted, Hashed files), and B+ Tree vs. Hash indexing.
- Parallel and Distributed Computing (PDC): GPU internal architecture, streaming multiprocessors, data flow architectures, SIMD/SIMT execution models, and high-throughput parallel workloads.
- Cyber Forensics & Information Security: Low-level hex inspection using HxD editor, disk image analysis with Autopsy and FTK Imager, SHA-256 hash verification, metadata forensics, Linux security, SQL injection prevention, and SIEM monitoring.
- Compiler Construction & Operating Systems: Lexical tokenization, syntax parsing, process scheduling, memory management, and concurrency control.
