# Academic & AI Engineering Projects README

During my Bachelor of Science in Computer Science (BSCS) at UMT Sialkot, I have built several practical software engineering and artificial intelligence applications that solve real-world problems:

1. EliteConnect AI (Proposal Engineering System):
I developed EliteConnect AI as an interactive Streamlit web application powered by the Google Gemini API. Freelancers often struggle to write tailored pitches quickly. EliteConnect AI analyzes a client's job description and automatically generates customized freelance proposals and executive email drafts, complete with PDF export functionality.

2. Scrollnix (Anti-Doomscrolling Mobile Utility):
I designed Scrollnix using React Native and Expo Go to help users combat excessive screen time and short-form video addiction. The application implements context-aware focus tracking and gentle intervention prompts to break mindless scrolling habits while maintaining a clean, distraction-free mobile user interface.

3. Smart AI Maze Runner (Mouse & Cheese Simulation):
For my Artificial Intelligence coursework, I built an interactive pathfinding simulation in Python and Streamlit. It implements the Steepest-Ascent Hill Climbing algorithm paired with Manhattan Distance heuristics to navigate a virtual mouse through dynamic obstacle grids toward a target goal, visualizing heuristic costs at every step.

4. SQL Query Tokenizer & Validator:
As part of my Compiler Construction coursework, I engineered a custom lexical analyzer and syntax validator in Python. The module tokenizes raw SQL strings and validates grammar rules for core Data Manipulation Language (DML) queries including SELECT, INSERT, UPDATE, and DELETE.
