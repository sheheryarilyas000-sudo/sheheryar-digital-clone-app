# Software Quality Engineering (SQE) & Security Testing Notes

One of my strongest technical foundations is Software Quality Engineering (SQE), manual black-box testing, and mobile application security evaluation. Throughout my undergraduate studies and practical testing projects, I have developed a structured methodology for identifying UI/UX edge cases, validating application logic, and writing reproducible bug reports.

When I test a web platform or an Android mobile application, I divide my workflow into four main phases:
1. Structured Functional Testing: I design comprehensive test cases covering positive flows, negative inputs, boundary value analysis, and equivalence partitioning. I verify that conditional validation and error-handling logic prevent crashes when unexpected data is entered.
2. Cross-Browser and Responsive UI Testing: Because users access web apps across varied screen sizes, I inspect layout prototypes and responsive breakpoints to catch visual regressions, overlapping elements, and broken navigation flows.
3. Network and API Traffic Inspection: I monitor client-server communication to verify that REST API endpoints return proper HTTP status codes, handle payload validation cleanly, and do not leak sensitive metadata in response headers.
4. Client-Side Storage Sandboxing & Security Evaluation: Backed by my Google Cybersecurity Professional Certificate V2 from Coursera, I inspect local storage, session tokens, and Android application sandboxing to ensure authentication states and user data are properly protected against unauthorized access.
